# COSC 581 HW 5
**Name:** Sarah Huang

**Assignment Title**: HW 5 (Programming Assignment 2)

**Assignment Description**: 
1) Write an algorithm to provide a Huffman encoding from the contents of a .txt file and apply it to compress the file. The program outputs the frequency table for the characters and the size of the file (in bytes) before and after the encoding.

2) Write an algorithm that takes as input a flow network in modified DIMACS format and prints all flow augmenting paths.


**Files**: 
- huffman.py - The final code that implements the Huffman encoding and compression.
- network_flow.py - The final code that takes a flow network and prints the flow augmenting paths.

**Use**:
- To run huffman.py program in the terminal, type "python  ./huffman.py  inputfile".
- To run network_flow.py program in the terminal, type "python  ./network_flow.py  inputfile".
