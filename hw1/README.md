# COSC 581 Programming Assignment 1
**Name:** Sarah Huang

**Assignment Title**: Programming Assignment 1

**Assignment Description**: 
Implement a quicksort algorithm that uses the median-of-medians algorithm to select the pivot table. 
r is set to 3, 5, 7, 9, and 11 to see the difference in behavior. 


**Files**: 
- quicksort.py - The final code that implements quicksort with median-of-medians algorithm.
- generate_inputs_quicksort.py - Quick program to generate input files with random numbers separated by new lines. 
- example_inputs folder - Example files I used to test, ranging from 10 to 1,000,000 numbers.

**Use**:
- To run in the terminal, type "python  ./quicksort.py  inputfile".
- The program will output each r value, the sorted numbers, and the duration of each quicksort at the end.
